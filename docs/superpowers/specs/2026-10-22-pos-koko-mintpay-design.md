# POS Koko and Mintpay

Add KOKO and MINTPAY as externally approved in-store payments alongside CARD. Require a non-empty provider reference and an amount equal to the full sale total. Store provider identity and reference on the existing paid POS order and show them on receipts. Preserve draft/pending intent recovery and clear references when switching methods. Use a compact two-column choice grid. No provider API calls or schema changes.
