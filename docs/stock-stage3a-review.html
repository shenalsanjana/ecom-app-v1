01 · Read-only findings

The shared-stock foundation is worth keeping.

The current model has explicit blank links and guarded stock deductions. Its main limitation is that every sale expects a blank and a DTF print; it has no separate finished balance or production state.

Live read-only snapshot · 19 October 2026: 25 blank rows, 40 print records, six physical families. Recorded blank availability: 175 units, excluding order allocations. This is not a shelf count.

The most important lifecycle gap: cancellation can restore a blank and print even if printing already happened, because there is no production record. Once materials have been used, release the reusable finished item or record waste.
Other gaps to address together
  • Plain products cannot publish or sell without a print.
  • Already printed goods have no independent stock pool.
  • Ready-made colour/size setup currently depends on blank stock choices.
  • Receipts and adjustments have no attributed inventory movement history.
  • Available quantities exclude allocations; entering a physical shelf count into that field can overstate stock.
02 · Recommended stock rules

Choose how each item is fulfilled.

Categories organise items. The fulfilment rule chooses which physical stock is reserved.

01 / PLAIN ITEM

Sell the blank directly

A plain T-shirt or unprinted bag uses its existing shared blank quantity.

Shared blank→Sale

No print required. No second copy of the blank's balance.

02 / PRINTED TO ORDER

Reserve, then make

Reserve the blank and print at order acceptance. Record when printing consumes them.

Blank + print→Order reservation→Printing

Preparation never deducts those same available materials again.

03 / READY-MADE

Sell the finished unit

An already printed design has its own finished stock by colour and size.

Finished stock→Sale

Materials were consumed during production. Selling deducts finished stock only.

Make stock: turn free blanks and prints into completed finished goods in one recorded transaction. Materials held for an existing order are handled through that order's reservation.

06 · Review before implementation

A practical rollout sequence.

3A.1 / FIRST SLICE

Plain sales + movements

Explicit plain/printed rules. Attributed movement records for every stock-writing path. Preserve all existing products as printed-to-order.

3A.2 / NEXT SLICE

Production + ready-made

Reservations, consumed-material protection, finished balances, preparation actions and optional ready-first/print-remainder allocation under one SKU. Reconcile physical opening counts before enabling ready-made sales.

3A.3 / BEFORE POS

Counts + inspected returns

Physical-state counts, discrepancy history and reusable/damaged returns. Then build POS on the same allocation service.

Release status: Stage 3A.1 (plain sales and movement history) was approved and deployed on 21 October 2026. Production, ready-made stock and mixed fulfilment still require review and approval. This simulator does not change live stock. Old orders cannot reveal whether their materials were physically printed; ambiguous cases need review.
Cancellation rules that must be agreed
  • Before printing: release the reserved, unused materials once.
  • Printing started: keep materials consumed; inspect work in progress.
  • Finished and usable: release finished stock. Personalised or damaged output stays unavailable.
  • Dispatched or delivered: receive and inspect a return. A refund alone does not restock an item.
Business decisions for review

Recorded preference: allow both ready-made and printing-to-order under the same SKU in the proposal. Actual usage is uncertain; implementation is still pending review.

Why this follows established patterns

Separating available, reserved and physical quantities follows Shopify's inventory states. Attributed changes follow its adjustment history pattern. A short component-to-finished workflow is supported by Odoo's one-step manufacturing pattern. This proposal applies those principles to Dressing Bear's existing pools.
