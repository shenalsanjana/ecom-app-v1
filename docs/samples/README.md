# Product review samples

These 78 fictional Sri Lankan examples cover the 26 published products that had no reviews when checked on 22 October 2026. Each product has three samples. Every preview entry identifies the review and author as fictional.

The JSON is a preview/testing fixture. All entries have `sampleOnly: true`, `synthetic: true`, `approved: false`, and `verifiedPurchase: false`. It is not imported into customer review records, product averages, review counts, or search structured data. Existing customer feedback is unchanged.

[Open the labeled preview](https://www.dressingbear.com/uploads/review-samples-20261022-6e47417f485e.html). The preview supports searching and filtering by product type and is marked noindex.
